Adapter pages should explain how Recite's engine-independent runtime contract is integrated into game engines.

The normative adapter contract lives in the [engine adapter contract](https://github.com/plethu/recite/blob/main/docs/engine-adapter-contract.md).

During pre-release development, adapter docs may point at packages and crates in
the source tree. Before Recite 1.0, the Godot, Bevy, and Unity adapters should
also be available in ecosystem-native distribution shapes so projects can add or
upgrade Recite without reverse-engineering the repository layout.
