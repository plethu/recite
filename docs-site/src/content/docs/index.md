Recite is a deterministic dialogue compiler, runtime, and tooling project for narrative-heavy games.

This site is the game-developer-facing manual. Start with [Install](/getting-started/install/) and [First Scene](/getting-started/first-scene/) for the current CLI workflow, or use the reference pages for command and source-format details.

The production design remains in the [production spec](https://codeberg.org/plethu/recite/src/branch/main/docs/recite-production-spec.md), and engine adapter details remain in the [engine adapter contract](https://codeberg.org/plethu/recite/src/branch/main/docs/engine-adapter-contract.md).

The initial deployment target for this scaffold is local static output from `pnpm docs:build`. No hosted deployment is configured in this issue.
