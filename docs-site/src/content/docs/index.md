Recite is a deterministic dialogue compiler, runtime, and tooling project for narrative-heavy games.

This site is the game-developer-facing manual. The production design remains in the [production spec](../../../../docs/recite-production-spec.md), and engine adapter details remain in the [engine adapter contract](../../../../docs/engine-adapter-contract.md).

The initial deployment target for this scaffold is local static output from `pnpm docs:build`. No hosted deployment is configured in this issue.
