---
title: Getting started
description: Install Recite, write a scene, and run it before connecting a game engine.
---

Start with a small scene you can read in full. You will give its lines and choices stable IDs, validate the source, compile it, and inspect a headless run.

1. [Install Recite](/getting-started/install/) and check the available commands.
2. [Write a first scene](/getting-started/first-scene/) with a line, a choice, and a destination.
3. [Run the complete example](/examples/headless-cli/) to work with a schema, conditions, effects, localisation, and traces.
4. [Connect an engine](/adapters/) when you are ready to present the scene in Bevy, Godot, or Unity.

For regular editing, follow the [authoring workflow](/guides/authoring-loop/). It covers the path from source changes and diagnostics to compiled assets and engine refresh.

If you already have dialogue in another format, read the [migration notes](/migration/) before converting a project. Each importer documents what it can preserve and what needs manual work.
