# recite

wip deterministic dialog runtime & tooling for ECS-oriented game development

Recite is currently early public work. The production direction is described in
[`docs/recite-production-spec.md`](docs/recite-production-spec.md).

## Contributions

External code contributions are not being accepted until the v1 shape has
stabilised. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the current policy.

## AI Usage Disclosure

Recite is adapted from dialogue tooling for a game I have been actively
developing for years. The architecture and review are mine.

Agentic AI tools are part of my development workflow. I would not have the
time to develop Recite as a standalone open source project otherwise.
