==================
Missing, empty and malformed IDs remain recoverable
==================
:: recovery default
>
  A header without an ID remains available while its ID is missing.
> speaker=hazel @
  An empty ID field remains visible while it is being typed.
> @Malformed
  A malformed ID remains attached to its line.
? requires=(trusts(player)) @NOT_AN_ID
  A malformed choice ID remains attached to its choice.
  -> END
?
  A bare choice header remains available while its ID is missing.
> @0123456789abcdef0123junk
  A digit-led ID with trailing junk remains one fragment.
> mood=calm @ez1fh09
  A generated ID follows the metadata.
  -> END
